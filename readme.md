TextBack 4.1.0 is an Android messenger. The answering machine is built into it.

Full SMS and MMS. Inbox, groups, pictures, search, scheduled send, reply from the notification. It has to be your default texting app. No account. Your texts stay on the phone. Android 10 and up.

When you need it, the machine is one button. Presets for sleeping, driving, work, vacation. It can turn itself off after a few hours, or on at night, in the car, or during a meeting. One reply per person until the timer you set runs out, so it doesn't ping-pong. Park one person on it, skip strangers, and still get a text if someone says urgent. If you haven't answered a starred chat, it tells them you're busy and you'll get back to them.

Textee shows up when a text lands, tells you who it was, and reads it out loud if you want. Morning summary says who texted and who you still owe. Lock a chat, blur a message, snooze one, polls, templates.

4.1 adds emergency mode: text up to five people, then answer everyone else until you turn it off. A line under the button that says if it can actually reply. Two SIMs. Undo a send. Backup to a Google Drive folder you pick. Wider screens get the list and the thread side by side.

Sideload the APK. Install over an older TextBack and it keeps your texts. First install will ask you to allow unknown apps, then set it as the default SMS app.
